Artemisia Desktop

A Linux desktop shell built with Rust and GTK4.

Artemisia is an experimental desktop shell project focused on creating a modern, lightweight, and user-friendly Linux desktop experience.

«[!WARNING]
Early Development: Extremely Experimental

Artemisia is currently in its very early stages of development. The project is actively being built, and its architecture, features, user interface, and behavior may change significantly.

It is not yet intended for daily use. Expect incomplete functionality, bugs, breaking changes, and missing features.»

About

Artemisia aims to explore an alternative approach to the Linux desktop experience, combining a native interface with practical controls and an approachable user experience.

The long-term goal is to build a desktop environment experience that is customizable and accessible to both new and experienced Linux users.

Current Status

Artemisia is a work in progress. Development is focused on establishing the project's foundations before expanding its functionality.

Current development includes:

- A desktop panel.
- An application launcher.
- A basic control center with volume and brightness controls.
- Integration with the MangoWC compositor.
- A modular Rust and GTK4 application structure.

These components are experimental and may change as development progresses.

Technology Stack

- Language: Rust
- GUI Toolkit: GTK4
- Window Compositor: MangoWC
- System Integration: Linux utilities and desktop services

Goals

The project's long-term goals include:

- A modern and lightweight desktop experience.
- An intuitive graphical settings interface.
- Modular components that are easier to maintain and extend.
- Practical desktop workflows with mouse and keyboard interaction.
- A welcoming experience for users who are new to Linux.
- An open-source development process.

These are development goals, not promises of currently available functionality.
